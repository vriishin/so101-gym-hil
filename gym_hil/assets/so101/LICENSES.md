# SO-101 asset provenance

The files in this directory derived from `Simulation/SO101` in
[`TheRobotStudio/SO-ARM100`](https://github.com/TheRobotStudio/SO-ARM100) at commit
`fda892cba81032c46c40976a48c9ceadbf40a9ca`.

Imported files:

- `robot.xml` from `so101_new_calib.xml`
- `so101_new_calib.urdf`
- `joints_properties.xml`
- the STL and source `.part` files under `assets/`

The upstream repository is distributed under the Apache License 2.0. A copy is available in the
repository root as `LICENSE`. The generated model cites the original Onshape CAD document in
`robot.xml`. The local `scene_pick_place.xml` is project-authored and includes the upstream robot model.
